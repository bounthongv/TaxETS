### **Algorithm for Calculating Benchmark Tax for a Single Company/Year**

**Input Data  Benchmark Calculation:**
*   `calculation_year`
*   `company_id`
*   `annual_turnover` (from financial data)
*   `sector` (from project/company data)
*   `is_accounting_holder` (Boolean: Yes/No - this is the user input you mentioned)
*   `actual_profit` (from financial data, only if `is_accounting_holder` is Yes)
*   `estimated_turnover` (user input, only if `is_accounting_holder` is No)
*   `business_activity_description` (for Mandatory regime, from project/company data)

---

**Step 1: Determine the Active Tax Regime**

*   Query the `benchmark_profit_tax_regimes` table.
*   Find the single row where the `calculation_year` falls between `valid_from` and `valid_to`.
*   Store the `regime_id` and all rules from that row (e.g., `standard_rate`).
*   **Crucially, fetch the turnover threshold that separates Micro from Standard enterprises for this regime.** We should add a field for this to our `benchmark_profit_tax_regimes` table. Let's call it `micro_enterprise_turnover_threshold`.
    *   For Regime 1 (2018-19), this value would be `240,000,000`.
    *   For Regimes 2 & 3 (2020+), this value would be `400,000,000`.

---

**Step 2: Classify the Enterprise Type (Micro vs. Standard)**

*   Compare the company's `annual_turnover` to the `micro_enterprise_turnover_threshold` from the active regime.
*   **IF `annual_turnover` <= `micro_enterprise_turnover_threshold`:**
    *   The company is classified as a **"Micro Enterprise"**.
    *   **Proceed to Step 3.**
*   **ELSE (`annual_turnover` > `micro_enterprise_turnover_threshold`):**
    *   The company is classified as a **"Standard Enterprise"**.
    *   **Proceed to Step 4.**

---

**Step 3: Calculate Tax for a "Micro Enterprise"**

*   Query the `benchmark_micro_enterprise_turnover_tax_rates` table using the `regime_id`.
*   Find the specific bracket where the company's `annual_turnover` is between `min_turnover` and `max_turnover`.
*   Follow the `calculation_method` for that bracket:
    *   If `ZERO`, `Tax = 0`.
    *   If `LUMP_SUM`, prompt the user to input the lump sum tax amount.
    *   If `RATE`, select the rate column (`production_rate`, `commerce_rate`, or `services_rate`) that matches the company's `sector`.
    *   `Tax = annual_turnover * selected_rate`.
*   **Calculation is complete for this company. End of process.**

---

**Step 4: Calculate Tax for a "Standard Enterprise"**

*   This is where your branch logic based on user input comes in.
*   Check the value of the `is_accounting_holder` input field for this company.
*   **IF `is_accounting_holder` == Yes (Pure Profit Tax):**
    *   Query the `benchmark_standard_rates_by_sector` table using the `regime_id` and the company's `sector`.
    *   If a sector-specific rate is found, use it.
    *   If not, use the default `standard_rate` from the main regime table.
    *   `Tax = actual_profit * tax_rate`.
    *   **Calculation is complete. End of process.**
*   **IF `is_accounting_holder` == No (Mandatory Income Tax):**
    *   **Step 4a (Estimate Profit):**
        *   Query the `benchmark_mandatory_profit_estimation_rates` table using the `regime_id` and the company's `business_activity_description`.
        *   Find the `profit_estimation_rate`.
        *   `Estimated_Profit = estimated_turnover * profit_estimation_rate`. (The `estimated_turnover` is the second critical user input you identified).
    *   **Step 4b (Calculate Tax):**
        *   Get the default `standard_rate` from the main regime table.
        *   `Tax = Estimated_Profit * standard_rate`.
    *   **Calculation is complete. End of process.**

### **Text-Based Flowchart: Calculation of Profit Tax TE**

**START: Calculation for a Single Enterprise in a Specific Year**

**[INPUT DATA]**

+ `activity_description`: Detailed business activity for the Mandatory regime (e.g., "Construction and repairs").
+ `is_accounting_holder`: User-provided boolean (YES/NO).
+ `actual_profit`: The real profit from financial records (if `is_accounting_holder` is YES).
+ `estimated_turnover`: User-provided turnover for estimation (if `is_accounting_holder` is NO).
+ `actual_tax_paid`: The actual amount of profit tax paid by the company.

+---> **[Store Result]**
      + `regime_id` (e.g., 3)
      + `standard_profit_tax_rate` (e.g., 0.20)
      + `micro_enterprise_turnover_threshold` (e.g., 400,000,000)

**STEP 2: Classify the Enterprise Type**
|
+---> **[Decision]** Is `annual_turnover` <= `micro_enterprise_turnover_threshold`?

      +-----> **YES: Enterprise is "Micro"** -> Go to **PATH A**
      |
      +-----> **NO: Enterprise is "Standard"** -> Go to **PATH B**

**PATH A: Calculate Benchmark Tax for a "Micro Enterprise"**
|
+---> **[DB Query]**
|     `SELECT * FROM benchmark_micro_enterprise_turnover_tax_rules`

|     `AND max_turnover >= [Input annual_turnover]`

+---> **[Decision]** What is the `calculation_method` from the query result?

      |       -> Go to **FINAL STEP**
      |
      +-----> **Case 3: `calculation_method` == 'RATE'**
              + **[Logic]** Select the correct rate based on `sector`.
              |   IF `sector` is 'Production' => Use `production_rate`
              |   IF `sector` is 'Commerce'   => Use `commerce_rate`
              |   IF `sector` is 'Services'   => Use `services_rate`

|
+---> **[Calculation]**
